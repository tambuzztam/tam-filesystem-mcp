# Source Code Directory

This directory contains the core implementation files for the TAM Filesystem MCP server.

The server extends the canonical MCP filesystem server with Obsidian-aware task and prompt management capabilities, along with enhanced README generation and discovery functionality.

## Key Components

- **Directory Analysis**: Intelligent analysis of directory structure and patterns
- **README Discovery**: Automatic discovery and processing of README files
- **Enhanced Listing**: Context-aware directory listings with README integration
- **Task Management**: Obsidian-aware task creation and tracking
